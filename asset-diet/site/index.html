Make your images lighter.

Asset-Diet is a practical Node.js command-line tool that optimizes image assets and shows you how much space you can save—without replacing your originals by default.

Why Asset-Diet

Optimize with confidence.

A focused tool for developers who want leaner assets and predictable file handling.

🛡️

Originals stay safe

Optimized copies go into a separate output folder by default. Use overwrite only when you deliberately choose it.

⚡

Less image weight

Use Sharp to process JPEG, PNG, WebP and AVIF files, and keep the original when an optimized result is larger.

📊

Clear savings reports

Review file-by-file results or request JSON output to plug reports into your own scripts.

🗂️

Recursive scanning

Walk image folders and subfolders while skipping common generated and dependency directories.

🧪

Preview first

Run a dry-run to estimate the effect before writing optimized files.

🎛️

Choose your quality

Adjust lossy image quality with a simple option to fit your project’s needs.

Simple workflow

Three steps to a lighter folder.

Install the tool, preview the result, then choose whether to write optimized copies.

01 / INSTALL

Set it up

Use Node.js 20 or newer and install Asset-Diet when the package is published.

02 / PREVIEW

Check savings

Run the dry-run option to see what could change without writing optimized files.

03 / OPTIMIZE

Review outputs

Generate optimized copies, compare the results, and use overwrite only when you intend to.

Get started

Try it from the repository.

The package is being prepared for npm publishing. Until then, you can clone the project and run it locally.

TerminalLocal setup
# Clone the repository
git clone https://github.com/godson-14/repo.git
cd repo/asset-diet

# Install dependencies and run tests
npm install
npm test

# Preview image optimization
node src/cli.mjs ./public/images --dry-run

After npm publication, the install command will be added here. Do not rely on npm install -g asset-diet until the package is confirmed published.
